## 👋 Sobre mí

Soy **Augusto**, estudiante de Informática en **ORT Argentina** y desarrollador full stack. Me gusta llevar una idea de punta a punta: diseñar la base de datos, armar la API y terminar en una interfaz que la gente use de verdad.

- 🚀 Tengo productos **en producción** y uno de ellos ya tiene **clientes reales**.
- 🗄️ Me interesa mucho el **diseño de bases de datos relacionales** y las arquitecturas que escalan sin complicarse de más.
- 🎨 También disfruto mucho el **frontend**: cuidar el diseño, las animaciones y la experiencia de usuario para que una app no solo funcione, sino que se sienta bien al usarla.
- 📱 Desarrollo para **web, mobile y escritorio**: Next.js, React Native y Tauri.
- 🔨 Hoy estoy trabajando en **proyectos independientes** como **CC360**, un sistema de cuentas corrientes para empresas.
- 🎯 Estoy **abierto a trabajo o pasantías** donde pueda sumar desde el primer día y seguir aprendiendo.

## 📂 Proyectos destacados

### 🅿️ SmartLot · *Cocheras para tu equipo, cerca de la oficina*
[![Sitio](https://img.shields.io/badge/Ver_sitio-smartlot.ar-7aa2f7?style=flat-square&logo=googlechrome&logoColor=white)](https://www.smartlot.ar/)
![Estado](https://img.shields.io/badge/estado-online-2ea44f?style=flat-square)

Plataforma que conecta **empresas con garajes que tienen lugares libres** cerca de sus oficinas.
- Reserva de cocheras para los equipos de cada sede y **acceso con código QR**.
- **Backoffice centralizado** para administrar empresas, con una estructura de roles y permisos.
- Un panel único para seguir el uso, **sin hardware especial** ni planillas manuales, lo que baja los costos de infraestructura.

### 🐶 LukeApp · *¿A quién le toca sacar al perro hoy?*
[![Repo](https://img.shields.io/badge/Ver_repo-LukeApp-181717?style=flat-square&logo=github)](https://github.com/AugusTraver/LukeApp)
![Estado](https://img.shields.io/badge/estado-con_clientes_reales-2ea44f?style=flat-square)
![Next.js](https://img.shields.io/badge/-Next.js-000?style=flat-square&logo=nextdotjs)
![Supabase](https://img.shields.io/badge/-Supabase-3FCF8E?style=flat-square&logo=supabase&logoColor=white)
![TypeScript](https://img.shields.io/badge/-TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)

App instalable (PWA) que organiza los **turnos de paseo del perro** en familia. **Ya la usan clientes reales.**
- Rotación automática de turnos, cambios entre integrantes, vacaciones y soporte para varios perros.
- **Notificaciones push** cada vez más insistentes, con acciones desde la notificación y un **cron** que corre cada 5 minutos.
- Login simple con código de familia y PIN, **modo sin conexión** y lógica de negocio pura **cubierta con tests** (Vitest).
- Backend en **Supabase** (PostgreSQL, migraciones SQL, auth anónima) y deploy en Vercel.

### 🔮 Nova · *Asistente de IA por voz para el escritorio*
[![Repo](https://img.shields.io/badge/Ver_repo-Nova-181717?style=flat-square&logo=github)](https://github.com/AugusTraver/Nova)
![Estado](https://img.shields.io/badge/estado-en_desarrollo-e3b341?style=flat-square)
![Tauri](https://img.shields.io/badge/-Tauri-24C8DB?style=flat-square&logo=tauri&logoColor=white)
![React](https://img.shields.io/badge/-React-20232A?style=flat-square&logo=react)
![Three.js](https://img.shields.io/badge/-Three.js-000?style=flat-square&logo=threedotjs)

App de escritorio que se abre con un atajo global: un panel translúcido con una **esfera 3D que reacciona a la voz** y widgets con la información del día.
- El asistente entiende pedidos por voz o texto y **ejecuta acciones** (eventos, recordatorios, consultas) mediante *tool calling*.
- Voz a texto con **Whisper** y texto a voz con **Piper**, ejecutados **localmente**.
- Datos personales en **SQLite local** y claves en el llavero del sistema; el objetivo es un costo de **$0**.
- Stack: Tauri 2 (Rust), React + TypeScript + Vite, Three.js, Framer Motion y Zustand.

### 👋 About me

I'm **Augusto**, a Computer Science student at **ORT Argentina** and a full stack developer based in Buenos Aires. I enjoy taking an idea from start to finish: designing the database, building the API and shipping an interface people actually use.

- 🚀 I have products **in production**, and one of them already has **real customers**.
- 🗄️ I'm especially into **relational database design** and architectures that scale without unnecessary complexity.
- 🎨 I also really enjoy **frontend work**: polishing design, animations and user experience so an app doesn't just work, it feels good to use.
- 📱 I build for **web, mobile and desktop** with Next.js, React Native and Tauri.
- 🔨 Currently working on **independent projects** such as **CC360**, an accounts-receivable management system for businesses.
- 🎯 **Open to jobs and internships.**

### 📂 Featured projects

- **[SmartLot](https://www.smartlot.ar/)**: connects companies with garages that have free spots near their offices. Includes QR access, a centralized backoffice with roles and permissions, and a single usage dashboard.
- **[LukeApp](https://github.com/AugusTraver/LukeApp)**: a PWA that schedules family dog-walking shifts, built with Next.js, Supabase and TypeScript. It has push notifications, cron jobs, offline mode and tested domain logic. **Used by real customers.**
- **[Nova](https://github.com/AugusTraver/Nova)**: a voice AI desktop assistant built with Tauri, React and Three.js. It does local speech-to-text and text-to-speech (Whisper and Piper) and uses tool calling to take actions. *In progress.*
- **CC360**: an accounts-receivable management system for businesses. *In progress.*
